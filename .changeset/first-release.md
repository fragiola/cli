The first release: `fragiola mcp`, an MCP server (stdio) that gives AI agents Fragiola UI's source components and the Fragiola libraries' docs and APIs, read from fragiola.com, and `fragiola mcp init --client <claude|cursor|vscode|opencode|codex>`, which writes the client's configuration. `fragiola/mcp` exports the same server.
